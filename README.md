# 🏥 Smart Healthcare Appointment & Patient Record Management System

A database-driven system that manages hospital operations such as patient records, doctor information, appointment scheduling, and billing while enforcing real-world constraints.

---

## 📌 Overview

This project simulates how hospitals digitally manage daily workflows using a centralized relational database.  
The focus is on **data integrity, access control, and correctness**, ensuring that appointments are conflict-free, billing remains consistent, and users interact with the system securely.

Built to demonstrate strong **DBMS fundamentals and software engineering principles**.

---

## ✨ Key Capabilities

- Role-based access for **Admin, Doctor, and Patient**
- Conflict-free appointment scheduling with time-overlap detection
- Automatic billing generation linked to appointments
- Secure credential handling with password hashing
- Conversational assistant for booking appointments using natural language
- Dashboard showing real-time system metrics

---

## 🧠 Design Highlights

- Normalized relational database schema
- Business rules enforced through validation logic
- Transactional workflow: **Appointment → Billing**
- Clear separation between data access and application logic

---
